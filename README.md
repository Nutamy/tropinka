# Тропинка — лендинг детского центра

Одностраничный сайт для детского развивающего центра «Тропинка» в Алматы: подготовка к школе, мини-группы по возрастам, логопед и изостудия.

**[tropinka.pages.dev →](https://tropinka.pages.dev/)**

![Тропинка — превью сайта](images/og-image.jpg)

## О проекте

Задача — конверсионный лендинг, который вызывает доверие родителей с первого экрана и ведёт заявку в WhatsApp: реальные фото центра и педагогов, отзывы и рейтинг с 2ГИС, понятные программы и цены, форма записи на пробное занятие.

Дизайн выстроен по принципам [Impeccable](https://github.com/pbakaus/impeccable) — сдержанная типографика, много воздуха, без визуального шума.

## Стек

- **Frontend** — чистые HTML/CSS/JS, без сборки и фреймворков
- **Backend** — Cloudflare Pages Functions (одна serverless-функция для формы)
- **Хостинг** — Cloudflare Pages
- **Антиспам** — Cloudflare Turnstile
- **Уведомления о заявках** — Telegram Bot API

## Возможности

- Форма заявки без перезагрузки страницы — заявка сразу приходит в Telegram
- Защита формы от спам-ботов (honeypot-поле + Cloudflare Turnstile)
- Галерея с лайтбоксом, адаптивная навигация, WhatsApp-кнопки с контекстными сообщениями
- Изображения в WebP/AVIF с fallback на JPEG/PNG
- Структурированные данные (schema.org `ChildCare`) для расширенных сниппетов в поиске
- Доступность: семантическая разметка, управление с клавиатуры, видимый фокус, `prefers-reduced-motion`
- Безопасность: строгий `Content-Security-Policy` и другие security-заголовки

## Структура

```
├── index.html               — вся страница
├── css/styles.css           — стили и UI Kit (палитра, типографика, компоненты)
├── js/main.js                — интерактив: меню, форма, галерея, анимации
├── functions/api/submit.js   — Pages Function: приём формы → Telegram
├── images/, fonts/           — статические ассеты (самохостинг шрифтов)
└── _headers                  — security-заголовки и кеширование
```

## Запуск локально

Сайт полностью статический — подойдёт любой HTTP-сервер:

```bash
npx serve .
```

Для проверки формы (Pages Function) нужен Wrangler:

```bash
npx wrangler pages dev .
```

## Деплой

Проект деплоится на Cloudflare Pages из Git-репозитория (build command не нужен, output directory — `/`) либо напрямую:

```bash
npx wrangler pages deploy . --project-name=tropinka
```

Функции требуют переменные окружения в настройках проекта Pages:

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен Telegram-бота, принимающего заявки |
| `TELEGRAM_CHAT_ID` | чат/группа, куда приходят заявки |
| `TURNSTILE_SECRET_KEY` | ключ проверки Cloudflare Turnstile |
